## Featured Projects

### InvoiceFlow — Professional Billing & Tax Portal
InvoiceFlow is one of the strongest full-stack repositories on this profile. It is a ReactJS, PHP, and MySQL-based billing portal built as a final major project, with a structured repository containing separate `frontend`, `backend`, `database`, and `screenshots` sections [1][2].

The project is aimed at freelancers, Kirana stores, and small businesses in India, and it includes multi-workspace management, dual profile support for business and freelance use, data isolation, dynamic dashboards, status tracking, payment history, and professional invoice generation [2]. It also includes Indian tax-oriented functionality such as GST support, HSN/SAC fields, PAN integration, print-friendly invoice layouts, and number-to-words formatting for rupee totals [2].

From a technical perspective, the frontend uses React, Tailwind CSS, React Router, and Lucide icons, while the backend uses object-oriented PHP with PDO and MySQL for secure data handling and session-based workflow separation [2]. The repository also documents API testing through Thunder Client and shows a product mindset centered on usability, modularity, and business relevance [2].

### RxShield — AI-Powered Prescription Analysis & DDI Checker
RxShield is an AI-powered prescription analysis desktop application that digitizes handwritten prescriptions, extracts medication-related information, checks for drug-drug interactions, and presents results through an interactive knowledge graph [1][3].

The repository includes structured folders such as `core`, `ui`, `tests`, `tools`, `presentation`, `Screenshots`, and `tested_images`, which makes it clear that this is more than a quick prototype and has gone through iterative development [3]. Its documented capabilities include OCR-based text digitization, dosage and drug extraction, patient-context-aware warnings, mandatory patient detail validation, multi-format report export, and visual graph-based interpretation of treatment relationships [3].

The stack listed in the repository includes Python, Kivy for UI, Google GenAI for OCR and reasoning, NetworkX and Matplotlib for graph visualization, ReportLab and python-docx for reporting, plus Pandas and SQLite for data handling [3]. This project stands out because it combines AI, healthcare safety, visualization, and desktop application design in a single system [3].
